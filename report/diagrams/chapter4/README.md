# Chapter 4 draw.io sources

## Figures 4.9 and 4.10

Open figures_4_9_and_4_10.drawio in diagrams.net/draw.io. The file contains two pages:

1. Figure 4.9 — Execution topology of the Stockrium analysis graph
2. Figure 4.10 — Execution flow of the Stockrium backtesting framework

To create thesis PNG files:

1. Select the required page from the page tabs.
2. Choose **File → Export as → PNG**.
3. Enable **Crop**.
4. Use 200–300% zoom for print-quality text.
5. Use a small border such as 10 px.
6. Export each page with its figure number in the filename.

The diagrams remain fully editable after import.
