\section{Experimentation and Backtesting Demo}
\label{sec:demo-experimentation-backtesting}

Figures~\ref{fig:stockrium-captures8}--\ref{fig:stockrium-captures11} demonstrate backtest configuration and reporting together with the corresponding controlled-analysis screens.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth,height=0.78\textheight,keepaspectratio]{screenshots/web1.png}
    \caption{Backtesting experiment configuration}
    \label{fig:stockrium-captures8}
\end{figure}

The configuration screen records the security or supported basket, evaluation period, benchmark, score threshold, transaction fee, lookback window, holding-period fallback, and analysis mode. Previously exported JSON artifacts and stored runs can also be reopened for inspection without rerunning the experiment.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth,height=0.78\textheight,keepaspectratio]{screenshots/web2.png}
    \caption{Backtesting experiment results}
    \label{fig:stockrium-captures9}
\end{figure}

The report combines summary metrics with a direct full-pipeline versus technical-baseline comparison. Entry and exit markers on the price chart and the associated trade journal make individual outcomes traceable; the displayed returns are historical results under the selected configuration, not evidence of guaranteed future profitability.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth,height=0.78\textheight,keepaspectratio]{screenshots/web3.png}
    \caption{Controlled stock-analysis experiment}
    \label{fig:stockrium-captures10}
\end{figure}

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth,height=0.78\textheight,keepaspectratio]{screenshots/web4.png}
    \caption{Controlled stock-analysis results}
    \label{fig:stockrium-captures11}
\end{figure}

The controlled-analysis interface can evaluate one symbol or a supported stock basket using automatic or manual configuration. Its result screen exposes the aggregate assessment together with the technical, fundamental, and news explanations, providing an administrative view for checking how the multi-agent output was assembled.

The demonstrated interfaces connect the specified user goals to the implemented application while preserving the boundary between decision support, controlled historical evaluation, and real securities transactions.
